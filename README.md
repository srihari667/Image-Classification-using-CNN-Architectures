#  Image Classification using CNN Architectures

### *DS-AG-022 – Deep Learning Assignment*

This repository contains solutions for **Assignment**, which focuses on implementing and understanding various **Convolutional Neural Network (CNN)** architectures and applying them to image classification tasks.



---

## 📘 **Assignment Questions Covered**

### ✅ **Q1 – CNN vs Fully Connected Networks**

Explanation of CNN architecture, convolutional layers, receptive fields, and comparison with classical dense networks.

### ✅ **Q2 – LeNet-5 Architecture**

Detailed description of layers, historical impact, and references to LeCun’s 1998 paper.

### ✅ **Q3 – AlexNet vs VGGNet**

Comparison of innovation, model depth, parameter count, performance, and limitations.

### ✅ **Q4 – Transfer Learning**

How pre-trained models reduce computation and help with limited datasets.

### ✅ **Q5 – ResNet and Residual Connections**

Explanation of skip connections and how they avoid vanishing gradients.
